# 数据库工作台

数据库工作台是云依助手中的本地 SQLite 工作区。它直接使用安装包内置的
SQLite C 引擎，不需要数据库服务器、Go 服务或网络连接。

## 打开与新建

进入“数据处理”后打开“数据库工作台”，可以：

- 通过 Windows 文件选择器打开 `.db`、`.sqlite` 或 `.sqlite3` 文件；
- 新建空 SQLite 数据库；
- 查看文件路径、大小、页大小、Journal 模式和 `user_version`；
- 随时刷新结构或关闭当前连接。

应用不会接受 React 传来的任意文件路径。只有原生选择器确认过的路径会保存在当前
进程内，关闭数据库或退出应用后即清除。

## 结构浏览

左侧结构树按表、视图、索引和触发器分组，支持折叠、按对象名、列名和类型筛选。
展开表或视图可查看列名和类型；主键有独立标记。点击对象只切换选择和展开状态，
不会覆盖编辑器中尚未执行的 SQL。

右侧“表结构”标签展示类型、主键、非空和默认值；“建表语句”只读展示对象创建 SQL，
支持复制。表／视图的“预览数据”以只读方式执行最多 200 行查询，即使编辑器开启写入，
预览也不会采用写入权限。预览 SQL 可在“执行信息”中查看，不会替换当前编辑内容。

## 固定工作区

- 顶部文件操作和一行统计始终可见；页大小、页数、Journal 和 user_version 收入“数据库信息”。
- 左侧结构树、右侧编辑器和结果表格分别滚动，长列表／SQL／结果不会撑长整个页面。
- 编辑器与结果之间的分隔条支持鼠标／触摸拖动、上下箭头以及 Home / End，范围为 30%–65%。
- 小窗口仍保持左右分区，可收起结构栏为右侧腾出空间；默认客户端初始大小和全局侧栏不变。

## SQL 编辑器

- `Ctrl + Enter` 或“运行 SQL”执行当前完整内容，语法高亮只用于显示，不改变 SQL；
- 支持用分号分隔的多条 SQLite 语句；
- 多语句仅显示最后一条的结果；“执行信息”保留实际执行 SQL、耗时、语句数和影响行数；
- 结果显示列名、行号和 NULL，固定表头、内部双向滚动；仅挂载可视行附近的数据，避免结果撑长页面；
- “复制结果”复制本次返回的表头和全部返回行，使用 TSV，包含 Tab、换行或引号的字段会正确加引号；
- 为控制内存与界面流畅度，最多返回 500 行，SQL 文本最多 256 KB；
- 超出 256 KB 的输入保留但禁止执行；500 行截断会有明显提示；
- BLOB 显示为 `<BLOB N bytes>`，不会把原始二进制塞进表格。

工作区默认处于“只读模式”。当执行选项 `allowWrite=false` 时，C++11 原生层会逐条调用
`sqlite3_stmt_readonly`，拒绝写入、删除和结构变更。需要修改数据库时，先切换到
“允许写入”，再确认每次执行。确认属于界面保护，桥接仍传递 `allowWrite`，不宣称可以
抵御任意篡改桥接消息。重要数据库应先自行备份，因为 SQLite 写入可能无法撤销。

所有打开／刷新／执行／关闭操作共用同步防重锁，连续快捷键不能并发提交。页面离开后
迟到的响应不再更新界面；关闭失败会保留当前连接信息，并显示具体错误。查询和预览
只是本地文件操作，不包含远程 MySQL / PostgreSQL、查询取消、单元格编辑或自动备份。

## 技术边界

| 层级 | 职责 |
| --- | --- |
| Win32 C | 打开/新建文件选择器 |
| SQLite C API | 数据库解析、预编译语句与结果读取 |
| C++11 | RAII 资源管理、路径限制、写入权限、UTF-8 与 JSON 适配 |
| React 18 | 结构浏览、SQL 编辑和结果展示 |
| SCSS Modules | 数据库工作区的组件级样式 |

对应实现位于 `native/src/DatabaseService.cpp`、`native/win32_c/src/file_dialog.c`
和 `frontend/src/toolbox/DatabaseStudio.tsx`。

## 回归测试

- `scripts/test-database-workbench-model.cjs`：SQL 标识符、显示分词和 TSV 转义。
- `scripts/test-database-workbench-ui.cjs`：隔离浏览器、纯内存桥接和合成数据库结构；验证分栏、
  标签页、筛选、六种窗口尺寸、拖动和键盘分隔、写入确认、防重、错误处理、500 行虚拟滚动和复制。
  不连接、修改真实用户数据库，不写系统剪贴板。
- `scripts/test-tool-removal.cjs`：被删除的数字格式化入口不可用，其他 C/WASM 工具保留。
- Release `MiloDatabaseServiceTests`：原生 SQLite 查询与只读保护回归。

界面测试默认使用 `http://127.0.0.1:3002/?mode=dashboard`，支持 `PACKET_TEST_URL` 和
`PACKET_TEST_BROWSER` 覆盖。内部 `database-studio` 标识和源文件名为兼容已有设置而保留，
用户可见名称统一为“数据库工作台”。
