# 常用工具专用工作区

桌面客户端 0.12.10 将九个通用工具改为按用途组织的界面，不改小助手、事项、全局侧栏或独立 Web 端布局。顶部沿用“返回工具列表 / 工具名”，不重复列表说明或技术栈标签。

## 操作设计

| 工具 | 操作区 | 结果区 |
| --- | --- | --- |
| Base64 | 编码/解码、URL 安全、保留补位 | 双栏编辑、UTF-8 字节统计、复制、反向转换 |
| Hex | 编码/解码、大写、字节空格分隔 | 双栏编辑、字节统计、复制、反向转换 |
| URL 编解码 | 组件编码/完整 URL 编码/解码 | 编码结果与原文对照、反向转换 |
| JSON | 格式化/压缩、2/4 空格缩进 | 可复制结果，可作为下一次输入 |
| 哈希 | SHA-256/MD5、待校验文本 | 摘要、长度、可选期望摘要及一致/不一致标志 |
| 时间戳 | 明确选择秒/毫秒、输入或填入当前时间 | UTC、本机含偏移时间、Unix 秒及毫秒，逐项复制 |
| UUID | v4/v7、生成数量 1–50 | 编号列表、逐项/全部复制 |
| 密码 | 含符号/字母数字/PIN、长度 4–128 | 默认隐藏、显示/复制/清空，不持久化 |
| 正则 | 表达式、g/i/m/s/u/y、测试文本 | 匹配高亮、位置与捕获组、定位和复制 |

主体占用当前可用高度。输入、输出、匹配列表和批量 UUID 分别内部滚动，长文本不会继续撑高整页。工具栏和状态区保持可达。Ctrl+Enter 执行当前工具；模式切换不自动发送请求。

## 正确性与边界

- Base64、Hex、URL、哈希、时间戳、UUID 和密码继续通过原有 C/C++11 本机桥接执行；不引入服务器、字体包或新依赖。JSON 使用本机 `JSON.parse/stringify`，遵循 JavaScript 数字精度，不作为任意精度数值处理器。
- 编解码针对 UTF-8 文本，不承诺将任意二进制转为可读文字。Base64 空文本是合法结果；Hex 的大小写和分隔只改变显示，不改变字节。
- URL 组件编码会转义 URL 分隔符，完整 URL 编码保留结构分隔符；解码可选择“加号转空格”（默认开启，兼容表单规则）。完整 URL 反向转换会关闭该选项并保留字面 `+`；反向转换保留最近的 URL 编码方式。
- 文本输入最多 1 MiB（UTF-8 字节）。字符统计按 Unicode 码点，行数将 CRLF 视作一个换行，不把表情误计为两个码点；空输入显示零行。组合字符并非字形统计。
- 时间戳只接受完整整数和显式单位，UTC 年份范围 0000–9999；结果保留毫秒精度，负时间戳不被错误取整。本机结果包含时区偏移。
- UUID 与密码仍使用 Windows 系统安全随机源。密码显示隐藏只减少屏幕暴露，不是内存加密；复制后系统剪贴板可能保留密码。MD5 仅兼容校验，不能用于安全认证或密码存储。
- 正则放在可终止的 Web Worker 中执行，2.5 秒超时终止，避免主界面被回溯阻塞。上限：测试文本 200,000 个 UTF-16 单元、表达式 4,096 单元、匹配 1,000 条、输出 600,000 单元、每捕获组 4,096 单元/32 组；截断会明确标记，用户输入不会静默截断。
- 不带 `g` 的正则只返回首个匹配。全局零长度匹配按 Unicode 规则向前推进，不会死循环。正则位置按 JavaScript 的 UTF-16 偏移计数，与编辑器选择范围一致。
- 请求开始即锁定重复执行。输入/选项修改使对应旧结果失效；迟到的请求或剪贴板回调不能冒充当前结果。失败时保留输入，复制/粘贴拒绝权限会显示可执行的手动操作提示。

- `node scripts/test-regex-model.cjs`：16 项正则语义/限制/Worker 终止测试。
- `node scripts/test-utility-workspaces-ui.cjs`：隔离浏览器与合成 WebView2 桥接，九工具操作、失败、过期结果、复制以及 1280/1024/760 × 800/600 六尺寸布局回归；不读真实剪贴板或数据库。
- 发布前再执行前端生产构建、Release 原生构建与 CTest。生成的新安装包包含生产 JS/CSS 及正则 Worker；不需要额外部署在线服务。
