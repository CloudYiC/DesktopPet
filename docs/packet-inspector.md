# 十六进制报文分析器

“十六进制报文分析器”用于把 Wireshark、串口日志或程序日志中的十六进制字节，
整理成可以按偏移检查的报文视图。它补充 Wireshark 的复制与二次分析场景，
不会在没有证据时猜测私有协议字段的含义。

从桌面版 `0.11.7` 起，该工具随 Windows 安装包完整提供。当前工具目录不维护启用或
停用状态，点击卡片上的“打开”即可进入分析工作台。

v1.0.0 起，Web 端已移除该工具的目录入口、独立页面和浏览器专用解析器；本说明
适用于 Windows 桌面端。桌面端已有功能与保存的字段不受影响。

## 输入与识别模式

工具接受连续十六进制、空格分隔字节以及带偏移和 ASCII 栏的 Wireshark hexdump。
输入首先在界面侧规范化，随后桌面版把字节交给纯 C 解析核心。

- `自动识别`：根据版本位和 EtherType 判断 Ethernet II、IPv4 或 IPv6；证据不足时按原始数据显示。
- `Ethernet II`：从二层帧头开始解析，并继续识别 VLAN、ARP、IPv4、IPv6、TCP、UDP 与 ICMP。
- `IPv4` / `IPv6`：适用于只复制了网络层及后续内容的情况。
- `TCP` / `UDP`：适用于只复制了传输层及后续内容的情况。
- `原始数据`：不套用任何标准协议结构，只显示偏移、字节和 ASCII。

解析器始终进行长度边界检查。报文被截断、协议声明长度超过实际输入、IPv6
扩展头暂未展开等情况会显示为警告，而不会越界读取或伪造字段。

## 自定义协议字段

私有协议没有公开结构或 Wireshark dissector 时，仅凭字节无法可靠知道字段名称、
类型和边界。此时可以在未知载荷上添加自定义字段：

- 名称、起始偏移和字节长度；
- 十六进制、无符号整数、有符号整数、ASCII 或 UTF-8 文本类型；
- 整数的大端或小端字节序。

自定义字段配置保存在桌面 WebView 的本机 `localStorage` 中，不上传报文内容。
点击标准字段或自定义字段都会高亮它覆盖的字节，方便与协议文档逐项核对。

## 区域用途

| 区域 | 适用场景 |
| --- | --- |
| 标准字段 | 按已识别协议查看字段含义与解析值，例如 IP 地址、UDP 源端口、长度；点击字段会定位其原始字节。 |
| 当前选区 | 检查所选原始字节的偏移、长度及大小端整数解释，复制片段或将范围定义为私有字段。 |
| 字节视图 | 对照整包 Hex 与 ASCII、协议分层色块，按偏移定位、Shift 连选，核对设备协议文档中的字节位置。 |

三者共用一个选区，功能互补。当前选区按完整字节解释整数，不等于标准字段的位级语义：
例如 IPv4 开头 `45` 的整字节值是十进制 `69`，但版本字段只取高四位，版本为 `4`。
私有载荷没有可自动推断的业务含义，应按设备协议文档定义字段名称、偏移、长度和类型。

## 分析工作台操作（0.13.12）

0.13.14 起，“已复制字节”“已保存字段”等成功反馈用右上角非占位轻提示，不再向输入卡
插入一行并推动结果区。复制失败保留在“当前选区”，字段无法保存到本机的错误留在字段区，
剪贴板读取失败的手动粘贴指引仍在输入框附近；解析降级提示属于结果状态，不自动消失。

工作台按“上方输入、左侧协议与选区、右侧字节与字段”组织，桌面版使用
`shared/packet-inspector/PacketWorkbench.tsx` 与 SCSS Module 样式。
默认及缩放后的可用宽度优先保持左右对照，不把整张协议卡放在字节视图前；真正窄屏才
改为上下排列，必要时保留自然滚动。每个载荷节点下直接放置其“定义载荷字段”入口，
点击会选中该段载荷，并将字段编辑器滚入可见区域及聚焦名称，不会发送或改写报文字节。

1. 粘贴报文，选择解析起点，点击“分析报文”或按 `Ctrl+Enter`。只有完整二层帧
   才应从 Ethernet 开始；若只复制了私有载荷，请选择“原始字节 / 自定义协议”。
2. 输入区可以收起，把空间留给分析结果。输入或模式改变后会标记“待重新分析”，
   避免把上一次结果误认为新报文结果。原生解析迟到的响应不会覆盖已经改过的输入。
3. 点击协议层或标准字段，字节视图、ASCII、当前层筛选和左侧选区解释联动。
   字节支持单击、`Shift` 连选及方向键移动；左侧可复制选中字节或定义字段。
4. 定位偏移接受十进制（如 `34`）或带 `0x` 的十六进制（如 `0x22`）。
   所有偏移均相对输入报文的第 0 字节；输入区的转储地址不作为自定义字段基准。
5. 每行默认自动适配宽度，也可手动切换 8、16、32 字节。字节和字段面板在内部滚动；最多 64 KiB 的报文
   使用可视行渲染，末尾字节也能定位，不再截取前 8 KiB。
6. “自定义字段”支持新增、修改和删除，整数解释支持 1–8 字节并使用 `BigInt`
   保留 64 位精度。长字段在表格中显示前 96 字节的预览，选区和复制仍使用完整范围。

旧版保存的字段仍可读取。换成较短报文时，超出范围的字段显示“超出当前报文”，
但仍允许编辑其偏移和长度；保存时重新检查边界。“清空”只清除当前报文与结果，
不会删除本机字段。未知载荷的含义必须来自协议文档，不会自动猜成业务包头。

## 实现边界

桌面版的标准协议解析位于 `native/c_core/`，保持 C 接口，C++11 的 `ToolService`
只负责输入限制和 JSON 桥接。网页专用解析器已移除，`shared/packet-inspector/` 继续
服务于桌面界面。分析工具不进行抓包、不访问网卡，也不代替 Wireshark 的重组、校验和
验证、TLS 解密与插件 dissector 系统。
