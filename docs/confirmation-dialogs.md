# 桌面确认弹窗（0.13.3）

所有业务确认复用 `frontend/src/components/ConfirmDialog.tsx` 和对应 SCSS，使用
body portal 与原生 dialog 顶层定位，居于整个客户端中央，不受右侧工作区变换、
滚动和宽度影响。普通弹窗宽 460px，SQL、设备参数、实名清理审查使用 580px 宽版；
视口较小时限制最大尺寸并允许内容滚动，不裁切按钮或长路径。

## 已接入范围

- 端口结束进程：保留冻结进程与端口、原生归属复核及关键进程保护。
- 软件标准卸载和残留清理：保留扫描计划、完整名称输入、个人数据警告与回收站边界。
- 数据库启用写入与每次执行 SQL：审查期间锁定数据库操作，冻结文件路径和 SQL。
  取消不执行，授权同步消费以避免重复提交；失败也消费本次授权，再执行必须重新审查。
- Modbus 写入：展示目标、功能、地址、数量和全部值，取消不写入，错误不自动重试。
- 衣柜删除上传角色：审查固定角色，确认前重新检查本机状态中该角色的名称、图片和内置
  属性；状态变化则停止并要求重新选择，内置角色仍不能删除。

默认焦点为取消，Tab/Shift+Tab 在弹窗内循环，Escape 在未执行时取消；异步执行期间
禁用重复确认和含糊取消。危险操作使用风险色按钮。背景不响应操作，取消后恢复发起控件焦点。

## 不替换的窗口

依依云朵是非模态互动面板；独立网页移动导航是菜单，不是业务确认。Windows 文件打开、
另存为窗口保留系统能力。COM/WebView 初始化失败时界面本身不能运行，保留原生 MessageBox
作为错误兜底，不依赖尚不可用的 HTML 弹窗。

## 验证

`node scripts/test-dialog-inventory.cjs` 扫描桌面和共享源码，阻止浏览器默认 confirm/alert/
prompt、额外 dialog 外壳和旧手工 modal 再出现。各业务测试使用隔离的合成原生桥接：

- `test-character-dialog-ui.cjs`：三套主题、大小字号、大小窗口、居中/焦点、取消、身份变动和重复确认。
- `test-database-workbench-ui.cjs`：两类确认、SQL/数据库锁定、重复执行、失败后重新审查和只读预览。
- `test-modbus-ui.cjs`：确认参数、键盘操作、布局、取消和写入错误不自动重试。
- `test-software-uninstaller-ui.cjs`：标准卸载与实名清理、完整路径、个人数据、取消和失败反馈。
- `test-port-manager-ui.cjs`：端口确认、取消与精确目标、保护状态和反馈。

这些测试不会删除真实角色文件、卸载真实软件、结束真实进程、写入用户数据库或连接实际设备。
