# 软件卸载与关联残留清理

## 0.13.3 统一确认组件

实名残留清理与标准卸载均复用公共 `ConfirmDialog`，取消为默认焦点，Tab/Shift+Tab
保持在弹窗内。清理仍必须准确输入完整软件名称，个人数据风险和全部已选路径完整保留；
仅弹窗外壳与表单样式统一，不改变原生清理计划或校验流程。

## 0.13.2 视觉更新

标题与信息区统一蓝灰色，主操作使用云青色；快捷方式、程序、个人数据分别以蓝、紫、
琥珀色辅助区分，文字标签和扫描依据完整保留。布局沿用固定详情和每页 5 项的设计。

标准卸载改用共享自定义确认框，默认焦点在取消，只有点击“启动卸载”才发送请求；
失败保留对话框供重试，处理中禁止重复提交。标准卸载与实名清理确认都居于整个客户端
中央，不使用浏览器原生确认框。清理保护、扫描边界与卸载后复查逻辑不变。

## 0.13.1 界面与工作流程

默认 1280 × 800 窗口下，左侧软件列表独立滚动；右侧采用“关联项目 / 软件信息”标签页、
每页 5 项的分类列表、固定路径详情与清理操作栏。大字号仍保持完整可用；小窗口允许
自然滚动，不通过缩小文字或隐藏控制项强行取消滚动条。

顶部不再常驻长篇保护说明或英文装饰标题。扫描限制以简短状态提示，并可在软件信息中
查看详情。点击“清理所选…”才弹出确认框，要求完整输入软件名称并确认个人数据风险。
复制位置与打开位置针对当前原生扫描计划中的精确项目，不执行快捷方式目标。

1. 从 Windows 卸载注册项读取软件列表，选择软件并扫描关联项目。
2. 经确认后启动软件自带的交互式卸载程序；“已启动”不代表卸载已完成。
3. 完成标准卸载后复查原计划中的残留，再审核选择并清理。刷新列表后，即使软件注册项
   已消失，本次页面仍保留软件及扫描计划，方便继续复查。

清理前原生层重新读取注册清单：软件仍注册时拒绝清理，关闭或取消卸载窗口不能跳过这一步。
软件清单由 Win32 C 读取；命令验证、扫描和短期清理计划由 C++11 SoftwareService 管理。
不拼接 rm -rf、del 或任意脚本命令。

## 通用关联扫描

不维护“特定软件名称 → 固定目录”的专用规则表。临时产品身份来自卸载项显示名称、注册项
键名、已验证注册 EXE 的文件名及版本资源（产品名、文件描述、公司名）等独立依据。
安装目录的叶名称不能自行证明产品身份；发布者共享目录不能直接作为整个产品的清理对象。

- 当前用户和公共的开始菜单、桌面位置通过 Windows Known Folders 获取，支持本地重定向位置。
- 在这些根目录内检查最多 6 层子目录，父目录名称无需匹配发布者。共享菜单下多层嵌套的
  产品快捷方式也可发现；只将关联 .lnk 文件列入结果，不把共享菜单父目录列为递归清理项。
- 读取 .lnk 保存的原始目标路径，不调用链接解析搜索、不启动目标、不访问 UNC/远程目标。
  目标必须匹配注册程序，或位于经独立产品身份核实的专属安装目录中；仅名字相似不算关联。
- Profile 顶层、LocalAppData、RoamingAppData、ProgramData 与 LocalAppData/Programs
  继续采用产品名精确匹配；发布者目录内最多检查一层精确产品名子目录，不做整盘模糊递归。
- 结果显示路径、依据、可信度与大小。个人配置默认不选择；专属自定义安装目录只作需复核项目，
  不默认勾选。不把其他软件或用户的通用资料文件夹当作安装目录。

整个扫描和大小统计共享约 4.5 秒的协作式时间预算、16,000 项预算及最多 40 个关联结果；
每个目录的枚举也有上限。受权限、重解析点、深度或预算影响时明确标记结果可能不完整。
操作系统单次文件调用仍可能有额外延迟，因此扫描在后台线程执行，支持取消，不阻塞 WebView。
旧请求通过世代标识失效，不会在用户切换软件后覆盖新选择。

## 原生保护

- 启动卸载前按软件 ID 与名称重新读取注册项。卸载命令只解析为明确的本地 EXE，调用时指定
  lpApplicationName；带空格的路径不再依赖模糊查找。裸 msiexec.exe 显式定位到 System32。
- 清理计划保存在原生层，包含随机令牌、15 分钟有效期、精确路径以及文件身份。WebView 不接收
  原生身份凭据，也不能自行添加候选路径。混入计划外路径会拒绝整次请求。
- 复查仅重新核对原候选：消失项移除、身份或快捷方式目标变化项排除，不扩展扫描范围。
  过期计划仅在原候选身份复核后续期，并清空默认选择，要求重新审核；不把新文件继承为旧清理授权。
  复查保留计划令牌，以便取消和返回交错时仍能安全重试，不扩大授权路径。
- 清理与打开位置前再次核对文件身份、快捷方式目标及路径组件；不跟随联接、符号链接或远程路径。
  清理期间固定祖先目录句柄，拒绝存在重解析点或无法完整安全检查的目录树。
- 拒绝磁盘、Windows、用户、AppData、Program Files、开始菜单、桌面和常见个人资料根目录。
- 使用 Windows 回收站操作，不提供永久强制删除回退。占用、权限不足或身份变化的项目保留并报告失败，
  不自动提升权限、不删除相邻或共享目录。
- 使用 IFileOperation 的显式回收标志及失败即停标志，见
  [Microsoft SetOperationFlags 文档](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)。
  分批清理只移除本次成功处理的候选，未勾选及失败项继续保留在同一计划内。

## 验证与边界

MiloSoftwareServiceTests 使用独立临时目录和合成 .lnk，覆盖四类位置、多层/改名链接、实际目标、
共享目录、联接与访问拒绝、取消与预算、文件身份与过期、卸载取消拦截、残留复查、明确 EXE 命令解析。
测试不枚举开发机软件、不调用真实卸载器、不清理真实用户文件。

scripts/test-software-uninstaller-ui.cjs 使用模拟原生消息验证分页、选择、固定布局、不同字号/窗口、
确认与取消、失败重试、旧扫描响应隔离及卸载后复查。桥接测试同时覆盖取消、复查令牌及打开位置请求。
浏览器预览不执行软件卸载、文件删除或真实 Explorer 操作；构建测试不等于已做安装/卸载实机测试。
