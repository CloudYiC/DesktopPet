# 图片转换器

桌面图片转换器位于“文件处理”，用于处理用户明确拖入或选择的单张本地图片。
原图由 WebView2 在内存中解码，缩放、旋转、翻转、质量调整和实时预览通过
Canvas 完成；纯色背景处理在本地 Web Worker 中执行，不会上传图片，也不会修改原文件。

## 支持范围

- 输入：PNG、JPEG、WebP、BMP 和 GIF；动画图片读取当前解码帧；
- 输出：PNG、JPEG、WebP 和单帧 256×256 Windows ICO；
- 尺寸：最长边最多 4096 像素，原图最多 20 MB、6000 万像素；
- JPEG 不支持透明度，剩余透明区域会合成到白色背景；
- ICO 保留原有青绿色圆角图标底板，透明图片会显示底板，不等同于无底板证件照；
- 保存时始终显示 Windows 原生位置选择和覆盖确认。

## 缩放与证件照尺寸

目前功能是像素缩放，不是裁剪。默认锁定原图宽高比；解锁后分别改宽高会拉伸图像。
旋转 90° / 270° 会交换最终输出宽高。每边限制为 1–4096 像素，比例锁定时同步限制另一边。

一寸／二寸描述的是成品尺寸，不等于随意修改宽高数字。正确制作还需要符合用途要求的
宽高比、取景／裁剪以及打印分辨率。当前没有一寸／二寸预设、裁剪框或 DPI 设置，
界面已注明这些边界，不宣称仅缩放就能生成符合所有要求的证件照。

## 纯色背景替换

1. 选择“替换纯色背景”。载入图片时会根据边缘像素估计原背景色。
2. 选择白、蓝、红、透明或自定义目标色。必要时点“从原图取色”，再点原图背景，
   或用“自动取色”重新估计；点击预览留白不会误取色。
3. 调整颜色容差和边缘柔化，并检查人物、衣服与发丝。支持并排对照和只看结果。
4. 预览完成后再保存。透明输出使用 PNG / WebP，JPEG 会转为白底。

算法从图片四边开始，只处理四邻域连通的近似底色；被主体包围的同色区域会保留。
它是纯色换底，不是 AI 人像分割：复杂、渐变或不均匀背景可能残留，衣服若与底色相近
且连到边缘也可能被替换。柔化只是颜色容差过渡，不承诺精细发丝抠图或自动去色溢。
未发现匹配区域会提示重新取色或调整容差。

“填充透明区域”只在已有透明／半透明像素下合成颜色，不会移除已有照片底色。
“保留原背景”是默认模式，不自动修改背景。

## 预览与安全边界

- 载入图片后，工作区按客户端可用高度布局：左侧参数独立滚动，右侧预览和保存按钮
  留在可见区域；小窗口仍保留左右布局，可切换“只看结果”增大单张预览。
- 参数变化有 140 ms 防抖，旧 Worker 会终止，像素 buffer 以可转移方式传递。
  保存只接受与当前原图及参数完全一致的预览；生成过程中禁用保存，避免保存旧结果。
- 迟到的文件解码不会覆盖更新的选择；原图 object URL 在更换或离开页面时释放。
- 不修改用户的原图、系统主题或小助手页面；原生层继续使用 C / C++11 保存管线。

普通图片编码由本机 WebView2/Chromium 编解码器完成。ICO 外壳由
`native/win32_c/src/icon_file.c` 的 C 实现生成；C++11 原生层限制格式、验证
PNG/JPEG/WebP 文件签名、限制解码结果为 32 MB，并以临时文件加替换方式完成保存。
React 不能向原生层提供任意目标路径。

## 回归验证

- `node scripts/test-image-background-model.cjs`：合成 RGBA 图验证四邻域、封闭同色保护、
  容差、柔化、透明度合成、边缘估色、输入验证和最大 4096×4096 图像。
- `node scripts/test-image-tool-ui.cjs`：隔离的 Playwright / Edge 页面使用合成图片验证
  换底像素、预览与保存状态、取色、格式、缩放／旋转以及不同窗口尺寸的独立滚动。
  不使用个人照片，不实际触发原生文件保存。
- `node scripts/test-tool-layout-ui.cjs`：现有全部工具导航和小助手页面布局回归。

界面测试需要本地前端预览（默认 `http://127.0.0.1:3002/?mode=dashboard`），
可通过 `PACKET_TEST_URL`、`PACKET_TEST_BROWSER` 指定地址和浏览器路径。
