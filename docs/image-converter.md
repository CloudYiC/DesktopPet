# 图片转换器

图片转换器位于“图片工具”，用于处理用户明确拖入或选择的单张本地图片。原图由
WebView2 在内存中解码，缩放、旋转、翻转、质量调整和实时预览通过 React Canvas
完成，不会上传到网络，也不会修改原文件。

## 支持范围

- 输入：PNG、JPEG、WebP、BMP 和 GIF；动画图片读取当前解码帧；
- 输出：PNG、JPEG、WebP 和单帧 256×256 Windows ICO；
- 尺寸：最长边最多 4096 像素，原图最多 20 MB、6000 万像素；
- JPEG 不支持透明度，透明区域会使用浅色背景；
- 保存时始终显示 Windows 原生位置选择和覆盖确认。

普通图片编码由本机 WebView2/Chromium 编解码器完成。ICO 外壳由
`native/win32_c/src/icon_file.c` 的 C 实现生成；C++11 原生层限制格式、验证
PNG/JPEG/WebP 文件签名、限制解码结果为 32 MB，并以临时文件加替换方式完成保存。
React 不能向原生层提供任意目标路径。
