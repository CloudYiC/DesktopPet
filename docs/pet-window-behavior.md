# 桌宠窗口与自动收起（0.13.16）

## 使用规则

| 状态 | 桌面依依 |
| --- | --- |
| 工作台正常打开 | 闲置角色暂时隐藏，减少遮挡 |
| 工作台右上角关闭、隐藏或最小化 | 恢复依依；关闭工作台不退出程序 |
| 工作台重新打开 | 恢复已最小化窗口，闲置依依暂时隐藏 |
| 到期提醒或十秒测试 | 工作台打开时也照常举牌，且不抢输入焦点 |
| 举牌展示结束、完成或延后 | 返回原位置，再按工作台当前状态决定显示或隐藏 |
| 托盘“暂时隐藏” | 保持手动隐藏，直到托盘“显示”；新的到期提醒仍可临时举牌 |
| 托盘“退出” | 程序退出，不再显示角色或处理提醒 |

举牌优先在正常显示的工作台所在屏幕居中；工作台隐藏/最小化时使用角色所在屏幕。
展示 12 秒后返回，关闭工作台不会再重复播放已经展示的提醒。

## 等待时间的含义

等待时间不是“启动程序后经过多久”，也不是“多久没点依依”，而是整台电脑连续无鼠标、
键盘操作的时间。支持 1、2、5、10、20、30、60 分钟。操作其他软件也会重置系统空闲时间，
恢复操作后依依会从边缘展开。工作台正在正常显示、用户手动隐藏或正在举牌时不执行缩边。

旧版有三个独立问题：最小化仍被当作可见工作台；未完成提醒在举牌结束后仍持续阻止收起；
缩边只露出窗口外侧 42px，但人物位于透明窗口中部，可能一像素人物都看不到。
0.13.16 将手动隐藏和工作台临时隐藏分开，按当前状态恢复；缩边保留半个宿主窗口，
两种内置角色布局都能露出一部分人物，而不是完全消失。

## 验证范围

- `MiloPetBehaviorTests`：直接运行生产所用纯 C 显隐/闲置策略，覆盖显示组合、反复打开关闭、
  最小化与恢复、手动隐藏、提醒临时覆盖、所有分钟选项及阈值前/到/后。
- `MiloReminderStoreTests`：独立临时数据库中的到期领取、延后、完成与重复提醒。
- `scripts/test-reminder-native-contracts.cjs`：校验原生动画、窗口和策略调用的源码接线，
  不冒充原生窗口实测。
- `scripts/test-reminder-presentation-ui.cjs`：真实等待十秒后由合成宿主发送事件，验证角色
  举牌、回位、完成和延后的 React 界面；使用公开/合成角色，不操作用户提醒。
- `scripts/test-tool-home-ui.cjs`：验证删去首页介绍横幅和品牌副标题后的布局与导航。

构建和上述测试不会安装/卸载程序、清空用户数据或改动用户正在运行的客户端。
Windows 多屏、置顶和真实系统键鼠闲置仍属于实机验收，不能用合成测试替代。
