# 桌宠窗口与快捷入口（0.13.17）

## 使用规则

| 状态 | 桌面依依 |
| --- | --- |
| 工作台正常打开 | 闲置角色暂时隐藏，减少遮挡 |
| 工作台右上角关闭、隐藏或最小化 | 恢复依依；关闭工作台不退出程序 |
| 工作台重新打开 | 恢复已最小化窗口，闲置依依暂时隐藏 |
| 到期提醒或十秒测试 | 工作台打开时也照常举牌，且不抢输入焦点 |
| 举牌展示结束、完成或延后 | 返回原位置，再按工作台当前状态决定显示或隐藏 |
| 托盘“暂时隐藏” | 保持手动隐藏，直到托盘“显示”；新的到期提醒仍可临时举牌 |
| 托盘“退出” | 程序退出，不再显示角色或处理提醒 |

举牌优先在正常显示的工作台所在屏幕居中；工作台隐藏/最小化时使用角色所在屏幕。
展示 12 秒后返回，关闭工作台不会再重复播放已经展示的提醒。

## 桌面快捷入口

点击人物，显示“打开工具台”“我的理财”“个人学习”。齿轮直达依依设置中的
“网站快捷入口”。两个网站地址默认留空；点击未配置入口只打开设置并定位输入框。
网站通过 Windows 默认浏览器打开，不嵌入工具台，不读取或保存网站账号、密码或内容。
普通启动、保存设置、切换页面、举牌提醒都不会自动访问网站。

地址支持 HTTP/HTTPS、内网域名、IP 和端口。其他协议、带账号密码的 URL、控制字符及
无效地址被拒绝；空地址表示取消该入口的链接。两项显式保存至本机 SQLite，错误和
成功反馈放在保存按钮附近，不使用挤占页头的提示条。旧用户数据、角色和提醒不清除。

## 定位与精简

- 人物和拖动框共享中心参照，不再混用固定右边距和百分比中心；拖动时暂停位移动画。
- 菜单按屏幕 DPI 预留空间，屏幕边缘自动避让；展开/关闭保持人物的屏幕锚点。
- 上下空间不足时改为左右展开；菜单展开时切换 DPI 以原人物中心恢复基础窗口。
- 拖动中到期提醒会撤销旧拖动，移动/松手不会干扰举牌轨迹或覆盖保存的位置。
- 保留原有角色素材及举牌动作，私有角色不作为独立源码素材提交。
- 删除自动收起和等待时间。旧 `pet.autoHide` / `pet.autoHideMinutes` 键不再读取或
  生效，不清除数据库；托盘手动隐藏和工作台打开时的临时隐藏不是自动收起，继续保留。
- 删除桌面“和我互动”及其动作子菜单；状态页原有动作预览不变。

## 验证边界

- `MiloPetBehaviorTests` 直接运行生产纯 C 策略；覆盖显隐、地址校验和菜单几何。
- `MiloReminderStoreTests` 使用独立临时数据库验证到期领取、延后、完成与重复提醒。
- 浏览器回归使用合成宿主、公开/合成角色验证菜单、设置草稿、缩放尺寸、保存反馈和
  举牌流程；不会访问用户网站或操作真实提醒。
- 原生源码契约检查只验证接线；原生 Release 构建和安装包解包核对不等于实机安装。
- Windows 多屏、系统缩放、默认浏览器关联和真实举牌仍需客户端实机验收。

构建和测试不会安装/卸载软件、清空用户数据或停止正在使用的客户端。
