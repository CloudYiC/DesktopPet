# 工作台详情布局（0.12.12）

桌面端所有 17 个工具共用 `shared/tool-workspace/ToolWorkspaceHeader.tsx`：
返回工具列表、分隔符和工具名称在同一行显示，不再单独占用一行返回按钮，
也不显示大图标和工具简介。简介只保留在工具列表，搜索仍能匹配简介。
报文分析器的网页版也复用该顶部组件。

## 空间分配

- 原生窗口首选尺寸仍为 1280 × 800；工作区适配和 DPI 行为不变。
- 常规侧栏由 216px 改为 192px；小于等于 780px 的视口使用 172px 侧栏。
- 所有工作台内容区统一上边距 12px、左右 16px、下边距 16px；窄窗口也保持一致。
- 依依的今天、全部事项、状态和设置页面保留原有标题与内容，只将外边距与工具页对齐。
- 助手设置使用紧凑主标题和顶部四标签，取消第二层左侧导航与重复说明；主题横排，设置行仅保留名称、操作控件和实际值。
- 设置页面按内容自然高度排版，不再强制 520px 最小壳体及大块填充；标准窗口无需多余滚动，小窗口仍允许自然滚动，不遮挡控件。
- 端口结束进程、软件卸载、数据库写入等安全与操作提示不属于工具简介，继续保留。

## 回归

启动前端本地预览，用 Node 20+ 和 Playwright 运行
`node scripts/test-tool-layout-ui.cjs`。
可通过 `PACKET_TEST_URL` 指定地址，通过 `PACKET_TEST_BROWSER` 指定浏览器路径。
检查全部工具的同排顶部、简介范围、空间尺寸，以及 1024/920/760 像素视口；
同时确认依依内容、工具页布局和原生首选窗口尺寸未改变，外边距按统一规则对齐。

`node scripts/test-settings-layout-ui.cjs` 额外检查助手设置的四个标签、主题/字号/启动
偏好操作、真实数据值与响应式空间。测试使用隔离配置与合成设置回包，不改本机实际偏好。

测试使用独立浏览器上下文，不触发原生连接、进程终止、卸载或数据库写入。
