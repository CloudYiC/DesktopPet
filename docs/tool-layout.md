# 工作台详情布局（0.13.10）

## MQTT 消息浏览与 Modbus 数据优先

0.13.10 将 MQTT 的连接、认证、订阅与发布集中到左侧操作栏，右侧由高消息列表占据。
列表展示载荷摘要与收发标识，支持主题/内容关键词和方向筛选；未选中不占用详情空间，
选中后打开可收起的侧边详情，默认及宽窗口与列表并排；更窄时使用带上/下一条导航的侧面区。
接收 RX 为绿色、发布 TX 为蓝色，载荷详情保留深色文本/HEX 视图。历史阅读、选中消息与新消息到达相互独立，
暂停跟随不停止订阅接收。右侧不再由消息表和黑色载荷框长期上下各分一半。

Modbus 保持左侧连接/请求、右侧数据表的结构，原始报文默认收起，仅保留紧凑入口与摘要；
展开时维持寄存器表的阅读空间，必要时允许外层滚动。数据支持筛选、线圈 ON/OFF 和同范围
轮询变化提示，读取过程中保留旧数据并明确刷新状态。外侧栏、窗口尺寸和写入确认保持不变。

两个工作区都按默认 1280×762、最大化、1024×640 缩放等效视口、窄窗口与大字号验证；
不通过缩小字体、裁切按钮或压扁消息区强行消除滚动。测试使用合成消息，不连接用户设备。

## 统一网络调试助手

0.13.9 将独立发包工具并入网络调试助手，工具总数恢复为 20。顶部仅保留协议模式；
连接与报文编辑在左侧，固定发送区同时支持单次、有限次数、持续发送、行尾和单独停止。
本地端口与连接按钮同排，正文编辑先于可选报文名称，优先让常用操作可见。
右侧保留可折叠的旧报文库与较高的彩色日志；TCP 服务端客户端列表与发送目标也在本页。
宽度超过 900px 使用左右布局，窄窗口自然上下；默认尺寸不变、内容边距不变。
没有并列两个旧工具页面，也没有清空旧报文库。详见 [网络调试与报文库](packet-sender.md)。

### 合并前的空间改进（现继续沿用）

0.13.8 优先保证日志阅读空间：黑色正文框至少 340px 高（上下内边距共 20px），
其余可用高度继续交给日志。空报文库只显示紧凑提示，有报文时保留 180px 列表卡，
并可用“收起/展开”保留标题及导入导出、临时收起内容，不修改已保存报文或网络会话。
状态信息换行、大字号、矮窗口导致放不下时，允许详情页面最右侧自然纵向滚动；
不再为了强制单屏而压扁正文。大量记录仍只在固定日志框内部滚动，不随消息增长撑高页面。

0.13.7 将发送网卡改成可见下拉框，提供刷新、本地端口、组播 TTL 和加入/退出操作。
左侧参数与内容可独立滚动，发送按钮和频率参数固定在工作区底部。
外部网络操作的确认框展示冻结的目标、网卡、端口与字节数；监听端口、目标和已加入状态
在右侧直接显示，不再仅靠报错提示用户手工寻找绑定选项。

0.13.6 新增第 21 个桌面工具，沿用统一详情导航、12px 顶部 / 16px 水平边距和工具配色。
宽度超过 900px 时左侧编辑目标、字节与发送参数，右侧上方是报文库，下方是彩色收发记录。
报文库、日志与必要的左侧设置分别内部滚动，不随记录增加撑高页面；窄窗口保留自然上下布局。
详细操作及通信边界见 [网络调试与报文库](packet-sender.md)。

## 其余工具配色统一

0.13.5 以软件卸载、端口管理及系统中心为基准，将其余 17 个工具统一为蓝灰标题、
暖白面板、浅蓝灰输入、清晰的边界与选中状态。配色集中在
`shared/tool-workspace/_toolPalette.scss`，仅工具导入，不覆盖外侧栏或依依页面。

- 编码与 JSON 工具：中性输入、淡青输出；哈希、时间、UUID 和密码的结果分别保留
  易识别的蓝/紫/青色信息层级，不改变现有输出或复制方式。
- 网络、串口、MQTT、Modbus：深蓝灰日志，发送琥珀、接收绿、状态蓝、错误浅红；
  连接、发送与结果面板用轻量淡色区分，现有左右分栏及内部滚动完全保留。
- 文本比较保留红删绿增、行内深色高亮；正则匹配绿、当前项金色；报文分析的协议层
  和字节区间颜色仍表示原有语义，不使用单色覆盖不同协议。
- 数据库用不同色区分结构、SQL 和结果区；图片工具只调整操作界面，透明棋盘改为
  中性灰，不改变图片像素、颜色或预览处理逻辑。
- 三种主题的主色仍可选择，实色主按钮适度加深，使启用的白字主操作达到 4.5:1；
  字号、字体、控件尺寸、布局断点、窗口大小和确认机制均不变。

`node scripts/test-tool-palette-ui.cjs` 比较 10 份新旧 Sass 编译结果中的非配色属性，
确认其他工具没有尺寸、字号或滚动规则变化，并在三个隔离主题下打开全部 20 个工具，检查
17 个同配色标题、主操作对比度、输入/输出区分及侧栏不受污染。网络、MQTT、Modbus 有意改布局，
其左右工作区与列表阅读高度改由专门尺寸测试覆盖。既有功能与布局 UI
回归继续覆盖通信、编码、文本比较、数据库、图片与报文分析。测试不访问真实设备或用户数据。

## 调试助手左右工作区

接收日志或数据结果。布局断点按整个内容视口判断，宽度超过 900px 保持双栏，只有
较窄窗口才上下排列；客户端初始大小、外侧栏宽度和内容边距不变。

- 左侧按地址/端口、发送选项等分组排版，不采用横跨整页的输入和结果三段布局。
- 默认 1280 × 762 内容视口同时显示操作和结果；最大化把更多空间交给右侧信息。
- 1024 × 640 等缩放等效视口和展开额外参数时，仅左侧按需内部滚动，右侧保持位置
  和高度；日志、结果表分别内部滚动，不随消息数量拉长页面。
- 窄窗口与极矮窗口保留必要的自然滚动；不缩小字体或裁掉按钮。未改变通信逻辑、
  LAN 监听确认及 Modbus 写入确认，MQTT 布局保持原样。

对应回归为 `test-network-debugger-ui.cjs`、`test-device-debuggers-ui.cjs` 和
`test-modbus-ui.cjs`，使用隔离浏览器和合成消息验证默认/大屏/窄屏、两种字号和

## 系统工具配色与弹窗

系统中心、端口管理、软件卸载统一蓝灰标题、暖白面板、云青主操作；分类和状态用
蓝、紫、青、琥珀色区分，同时保留中文标签，不只依靠颜色表达含义。

- 系统中心用四张彩色概览卡展示系统、CPU、内存与存储，详细信息分为四个标签页；
  原有 34 个字段完整保留，默认窗口与大字号不需要页面滚动，窄窗口自然换行。
- 端口管理使用固定高度工作区，只有端口表格内部纵向滚动；长地址和进程名换行，
  操作列保留完整宽度。小窗口改为条目卡片，不通过裁切隐藏操作和横向溢出。
- 端口结束进程与标准卸载使用共享 `ConfirmDialog`，通过 body portal 和原生
  dialog 顶层居中于整个客户端。默认焦点在取消，Tab 保持在对话框内，Escape
  取消；处理中不能重复确认，失败时保留目标与错误供重试。
- 软件卸载继续使用固定详情与分页，快捷方式、程序、个人数据分别标色；清理确认
  也居于客户端中央，完整名称和个人数据风险确认不变。

不再常驻显示端口安全说明。结束进程的影响在确认框中展示，原生端口归属复核和
关键 Windows 进程保护保持不变。此次视觉调整不增加字体依赖，不改变窗口尺寸。

软件卸载使用紧凑双栏：左侧安装列表独立滚动，右侧关联项目按每页 5 项分页；
软件信息切换到独立标签页，路径详情及清理操作固定在底部。默认窗口不让右侧随
结果数量向下增长；矮屏或窄屏保留自然滚动，不隐藏关键操作。常驻说明条移除，
完整名称及个人数据风险在清理确认对话框中展示。

最外侧导航改为 `NavIcon` 的统一线条 SVG；`aria-hidden` 避免读屏重复读出装饰，
选中项提供 `aria-current`。不加载图标字体、外部图片，不改导航名称与事项功能。

桌面端所有 20 个工具共用 `shared/tool-workspace/ToolWorkspaceHeader.tsx`：
返回工具列表、分隔符和工具名称在同一行显示，不再单独占用一行返回按钮，
也不显示大图标和工具简介。简介只保留在工具列表，搜索仍能匹配简介。
报文分析器的网页版也复用该顶部组件。

## 空间分配

- 原生窗口首选尺寸仍为 1280 × 800；工作区适配和 DPI 行为不变。
- 常规侧栏由 216px 改为 192px；小于等于 780px 的视口使用 172px 侧栏。
- 所有工作台内容区统一上边距 12px、左右 16px、下边距 16px；窄窗口也保持一致。
- 依依的今天、全部事项、状态和设置页面保留原有标题与内容，只将外边距与工具页对齐。
- 助手设置使用紧凑主标题和“常规 / 本机数据 / 关于”三个顶部标签，取消第二层左侧导航与重复说明；主题横排，设置行仅保留名称、操作控件和实际值。
- 工具目录保留名称搜索，移除无实际权限作用的状态筛选与 `Local`、`Available`、`Popular` 标签；20 个内置工具的卡片统一直接“打开”。
- 设置页面按内容自然高度排版，不再强制 520px 最小壳体及大块填充；标准窗口无需多余滚动，小窗口仍允许自然滚动，不遮挡控件。
- 结束进程和软件卸载的风险在相应确认框中展示，移除端口常驻保护说明；原生保护与数据库写入确认保持不变。
