# 系统中心、端口管理、软件卸载、数据库与模块权限

## 系统中心

系统中心只读取以下本机信息：

- Windows 版本、版本号、Build、安装日期和 CPU 架构；
- 计算机名称、当前 Windows 用户、设备厂商/型号和 BIOS 版本；
- CPU 型号、物理核心、逻辑处理器、插槽数量、标称频率和固件虚拟化状态；
- 物理内存、提交量、系统盘容量与当前使用率；
- 主显示适配器、主屏幕分辨率和 DPI；
- 当前活动网络适配器、主要本地 IPv4、时区与系统区域；
- 外接电源/电池状态、开机时间和持续运行时间。

指标由 `native/win32_c/src/system_metrics.c` 中的 Win32 C 探针读取，字符串转换和 WebView2 JSON 边界由 C++11 管理。读取使用 Windows API、只读注册表查询和网络适配器枚举；系统中心不会修改注册表、系统设置或硬件配置，也不会把快照上传到网络。

某些字段可能由设备固件或 Windows 驱动标记为不可用，界面会显示“未报告”，不会用猜测值代替真实数据。IPv4 仅展示本机当前适配器地址，不会请求公网 IP 服务。

## 端口管理

端口列表使用 Windows IP Helper API 读取 IPv4 TCP/UDP 端点和拥有者 PID。C++11 层只为当前可查询的进程补充可执行文件名称。

结束进程需要同时满足：

1. 用户在界面中确认包含进程名称与 PID 的警告。
2. 原生层重新枚举端口，确认该 PID 和进程名称仍然拥有可见端口。
3. 目标不是本程序、PID 0/4、已知系统进程或 Windows 标记的关键进程。
4. 当前 Windows 权限允许打开并结束该进程。

任何一项失败都会拒绝操作。测试只覆盖“关键进程”和“伪造端口归属必须被拒绝”，不会结束测试机器上的真实进程。

当前端口列表先支持 IPv4；IPv6 将在后续版本补充。

## 软件卸载

软件卸载模块通过 Win32 C 读取 HKCU/HKLM 的 32 位与 64 位卸载注册项。界面不扫描
整块磁盘来猜测软件，也不会显示 Windows 标记的系统组件。启动卸载前，C++11 层会按
软件 ID 和显示名称重新读取注册表，只执行该记录自己的 `UninstallString`。

关联残留先由原生层生成短期清理计划。前端只能从计划内勾选精确路径，不能提交任意
目录、通配符或命令；原生层始终拒绝磁盘根目录、用户根目录、Windows、Program Files、
LocalAppData 和 RoamingAppData 根目录。Profile、AppData 或 ProgramData 中通过通用
身份匹配找到的目录统一标记为个人数据且默认不选。执行清理需要完整输入软件名称并再次确认，文件会进入
回收站而不是不可恢复地强制删除。完整说明见
[`software-uninstaller.md`](software-uninstaller.md)。

## 数据库工作室

数据库工作室仅连接用户通过 Windows 原生文件选择器明确选中的 SQLite 文件。WebView
消息不能传入任意文件路径，后续刷新和 SQL 执行只能访问原生进程当前保存的数据库路径。

- 打开数据库后默认使用 SQLite 只读连接；
- 原生层使用 `sqlite3_stmt_readonly` 逐条检查语句，前端开关不能绕过只读限制；
- 开启写入需要一次确认，每次执行写入模式 SQL 还会再次确认；
- 单次 SQL 文本上限为 256 KB，结果最多返回 500 行，避免 WebView 消息无限增长；
- BLOB 只显示字节数，不把任意二进制内容传进界面；
- 数据库文件始终留在本机，不上传到 CloudYi 或其他网络服务。

SQLite 引擎使用官方 C API，文件选择器使用 Win32 C；数据库连接、资源释放、UTF-8
转换、权限检查和 WebView2 JSON 边界由 C++11 管理。完整使用说明见
[`database-studio.md`](database-studio.md)。

## 图片转换器

图片转换器只读取用户拖入或通过浏览器文件控件选择的图片。编辑和预览在本机
WebView2 Canvas 中完成；保存时 React 仅提交经过编码的图片内容与格式，不提供目标
路径。目标位置由 Win32 C 保存对话框选择，C++11 层验证格式、签名和 32 MB 上限，
并通过临时文件替换保存。原图不会被覆盖，详细范围见
[`image-converter.md`](image-converter.md)。

## 内置模块管理

模块管理目前只管理应用内置并可实际使用的工具：

- 展示工具需要的本地计算、系统读取或进程控制权限。
- `Local` 表示已经启用，`Available` 表示安装包内置但尚未启用；对应操作为 `Open` 和 `Enable`。
- 模块管理可以移除或重新安装这些内置登记，功能代码仍随应用安装包统一升级。
- 状态保存在 WebView2 本地配置，不需要 CloudYi 账户。
- 移除后工具入口显示为 `Available`；重新安装后恢复为 `Local`。

外部插件包的签名校验、解包、版本升级、卸载和沙箱执行尚未实现，因此外部插件入口暂不显示。

内置模块登记属于功能偏好，不替代原生安全检查。即使 WebView 消息被伪造，进程控制仍必须通过 C++11 原生层的重新验证。
