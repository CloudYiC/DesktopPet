# 文本比较（0.12.7）

桌面端的文本比较使用独立的 React 工作区（`TextDiffWorkspace.tsx`），保留统一的紧凑顶部，不影响其它工具或依依页面。

## 使用

- 左侧原始文本，右侧修改后文本。点击“开始比较”或按 Ctrl + Enter 更新结果。
- 行级对齐后，红色表示删除/修改前，绿色表示新增/修改后；更深的色块表示行内具体改动，正负号提供非颜色区分。斜纹占位表示该侧没有对应行。
- 新增、删除、修改分别统计行数；修改行不再重复计入新增/删除。连续的变动行合为一处差异，可用上下箭头跳转。
- “只看差异”隐藏未变化的行；输入区域可收起。结果使用单一固定高度滚动区，让左右始终对齐，长行自动换行。
- 文本或比较选项更改后，会明确提示当前仍是上次结果；重新比较前禁用差异复制和跳转。
- “忽略行首尾空白”仅影响匹配，不改变输入和原始显示。CRLF、LF、单独 CR 视为相同换行符；有无末尾换行仍能区分。

## 实现与边界

`textDiffModel.ts` 是无依赖的 TypeScript 模型，使用有计算预算的行级 Myers 匹配与锚点回退，行内高亮以 Unicode code point 为单位（不切开代理对，但不是完整字素簇分析）。不会再将插入一行后的所有行误判为修改。

单侧输入上限为 3,000 行、200,000 个 UTF-16 码元；超限时拒绝比较并保留输入，不静默截断。差异复杂度超过预算时，采用简化对齐/区段高亮，并在界面明确提示，不宣称最小编辑距离。所有文本仅在当前窗口内存中处理，不上传、不持久保存。复制输出是带正负号的可读文本，不是可直接应用的补丁文件。

## 验证

- `node scripts/test-text-diff-model.cjs`：行对齐、行内高亮、空白/换行、Unicode、随机重建和大文本预算。
- `node scripts/test-text-diff-ui.cjs`：隔离浏览器中的高亮、跳转、筛选、复制、固定滚动和自适应布局。
- `node scripts/test-tool-layout-ui.cjs`：20 个工具与依依页面的紧凑布局回归。

UI 测试可通过 `PACKET_TEST_URL` 和 `PACKET_TEST_BROWSER` 指定本地预览及浏览器；截图输出到忽略目录 `artifacts/text-diff/`。测试剪贴板使用内存替身，不覆盖系统剪贴板。

3,001 行的超限用例通过原生 textarea 赋值与 `input` 事件验证 React 上限校验。当前 Edge 环境的自动化 `fill` 多行输入命令在内容已送达后仍可能超时，因此该用例不代表完整的真实巨量粘贴流程已经验证。
